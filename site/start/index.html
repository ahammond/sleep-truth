Get started

From nothing to a printed sleep timeline in about 15 minutes. You type a few commands in a terminal; the steps below give each one.

Sleep Truth is early. Today it runs on a Mac, from the command line. A simpler path for people who don't use a terminal is the goal, not the present.

1. Install the tools

Install git and mise. mise installs the versions of Node and pnpm that Sleep Truth expects.

2. Get the code

git clone https://github.com/ahammond/sleep-truth.git
cd sleep-truth
mise trust
mise exec -- pnpm install
mise exec -- pnpm -C packages/web build
mkdir -p ~/.local/bin
ln -sf "$PWD/bin/sleep-truth" ~/.local/bin/sleep-truth
sleep-truth --help

The last command prints the sleep-truth commands. If it says command not found, run echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc, open a new terminal window, and try sleep-truth --help again. From here on, sleep-truth works in any directory.

3. Connect your device

Follow the setup page for your device. It ends with sleep-truth setup, which saves your device app's keys on your computer.

  • Oura Ring

4. Sign in

sleep-truth login

Your browser opens your device maker's sign-in page. Approve access, and the terminal says Login complete.

5. Download your data

sleep-truth sync

The first run downloads up to a year of sleep records to your computer. Later runs start a few days before the newest night you have. To download less the first time, add a start date: sleep-truth sync --since 2026-09-01.

6. Export the nights you want

sleep-truth export --from 2026-09-01 --to 2026-11-26 -o ~/sleep.nights.json

This writes one file with the nights in that range. It is yours: keep it, share it, or delete it.

7. View and print

  1. Open packages/web/dist/index.html, inside the sleep-truth folder, in your browser.
  2. Choose the file, or drop it on the page. Nothing is uploaded; the page works offline.
  3. Pick Printable for black and white, or Colour.
  4. Press Print. Choose US Letter, landscape. Save as PDF if you want to send it.

The newest night comes first and the dates run backwards from there. Each row is one night, from 8 PM to noon, on your local clock.

Keep it up to date

Before each doctor's visit, run sleep-truth sync and sleep-truth export again, then print.

Delete your data

sleep-truth forget

This cancels Sleep Truth's access and deletes the downloaded data from your computer. It keeps the settings file with your Oura app keys, which holds no health data. Delete any exported files yourself.

Problems

If the browser can't return to the terminal after you sign in, run sleep-truth login --paste instead and paste the address you land on. For anything else, open an issue on GitHub.

Sleep Truth shows data recorded by a consumer wearable. It is not a medical device, not a diagnostic tool, and not medical advice.
