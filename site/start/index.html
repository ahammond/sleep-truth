Get started

From nothing to a printed sleep timeline in about 15 minutes. You type a few commands in a terminal; the steps below give each one.

Sleep Truth is early. Today it runs on a Mac, from the command line. A simpler path for people who don't use a terminal is the goal, not the present.

1. Install the tools

Install git and mise. mise installs the exact versions of Node and pnpm that Sleep Truth expects.

2. Get the code

git clone https://github.com/ahammond/sleep-truth.git
cd sleep-truth
mise trust
mise exec -- pnpm install
mise exec -- pnpm -C packages/web build

The rest of the commands run from this sleep-truth directory.

3. Connect your device

Follow the setup page for your device. It ends with a small settings file at ~/.config/sleep-truth/config.json.

  • Oura Ring

4. Sign in

mise exec -- pnpm -C packages/cli start -- login

Your browser opens your device maker's sign-in page. Approve access, and the terminal says Login complete.

5. Download your data

mise exec -- pnpm -C packages/cli start -- sync

The first run downloads up to a year of sleep records to your computer. Later runs fetch only the last few days. To download less the first time, add a start date: sync --since 2026-09-01.

6. Export the nights you want

mise exec -- pnpm -C packages/cli start -- export --from 2026-09-01 --to 2026-11-26 -o ~/sleep.nights.json

This writes one file with the nights in that range. It is yours: keep it, share it, or delete it.

7. View and print

  1. Open packages/web/dist/index.html in your browser.
  2. Choose the file, or drop it on the page. Nothing is uploaded; the page works offline.
  3. Pick Printable for black and white, or Colour.
  4. Press Print. Choose US Letter, landscape. Save as PDF if you want to send it.

The newest week comes first. Each row is one night, from 8 PM to noon, on your local clock.

Keep it up to date

Before each doctor's visit, run sync and export again, then print.

Delete everything

mise exec -- pnpm -C packages/cli start -- forget

This cancels Sleep Truth's access and deletes the downloaded data from your computer. Delete any exported files yourself.

Problems

If the browser can't return to the terminal after you sign in, run login --paste instead and paste the address you land on. For anything else, open an issue on GitHub.

Sleep Truth shows data recorded by a consumer wearable. It is not a medical device, not a diagnostic tool, and not medical advice.
